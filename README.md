# Appendix B. Projection Procedure 설명

Appendix B는 Mori et al.의 예측 절차를 실제로 어떻게 계산하는지 설명하는 부분이다.  
전체 구조는 크게 세 단계로 나눌 수 있다.

1. **B.1 Parameter estimation**: 관측자료를 이용해 모형을 미리 학습하는 단계  
2. **B.2 City-level projection**: 도시 단위 인구 예측값 `P_hat`을 만드는 단계  
3. **B.3 Grid-level projection**: 격자 단위 인구 예측값 `p_hat`을 만들고, 이를 도시군 구조와 맞추는 단계  

핵심은 도시 인구와 격자 인구를 따로 예측한 뒤, 두 결과가 서로 모순되지 않도록 반복적으로 조정하는 것이다.

---

# 1. B.1 Parameter Estimation

B.1은 미래를 예측하기 전에, 관측기간 자료를 이용해 필요한 모형들을 미리 학습하는 단계이다.

예를 들어 Mori 연구에서는 1970년부터 2020년까지 5년 단위 격자 인구자료를 사용한다. 먼저 각 시점마다 도시군을 식별한다. 도시군은 인구밀도 기준을 넘는 격자들이 공간적으로 연결되어 있고, 그 총인구가 일정 기준 이상일 때 하나의 도시로 정의된다.

즉, 다음과 같은 순서로 진행된다.

    1970년 격자 인구 → 1970년 도시군 식별
    1975년 격자 인구 → 1975년 도시군 식별
    1980년 격자 인구 → 1980년 도시군 식별
    ...
    2020년 격자 인구 → 2020년 도시군 식별

각 연도별 도시군을 식별한 뒤에는, 서로 다른 시점의 도시군이 같은 도시인지 연결해야 한다. 이때는 두 시점의 도시군이 공간적으로 겹치는 격자를 찾고, 그 겹치는 격자 안의 기준시점 인구를 이용해 도시 ID를 이어준다.

이 과정을 통해 도시별 인구 시계열이 만들어진다.

예를 들어 도시 A의 인구 시계열은 다음과 같이 구성될 수 있다.

| 연도 | 도시 A 인구 |
|---|---:|
| 2000 | 2,000 |
| 2005 | 2,200 |
| 2010 | 2,350 |
| 2015 | 2,500 |
| 2020 | 2,600 |

이 도시별 시계열에 대해 여러 단순 시계열 모형을 적합한다. Mori 연구에서는 도시별로 ARI1, ARI2, CS, LL 모형을 사용한다.

| 모형 | 의미 |
|---|---|
| ARI1 | ARIMA(1,1,0) |
| ARI2 | ARIMA(2,1,0) |
| CS | 현재 인구가 유지된다고 보는 상수 모형 |
| LL | 시간에 대한 로그-선형 모형 |

동시에 국가 수준에서는 도시 규모분포가 power law를 따른다고 보고, 각 시점마다 다음 식을 적합한다.

`log(P_u,t) = A_t + B_t * log(R_u,t - 0.5) + error`

여기서 `P_u,t`는 도시 `u`의 인구, `R_u,t`는 도시의 인구 순위, `A_t`와 `B_t`는 해당 시점의 도시 규모분포를 나타내는 계수이다.

각 시점에서 `A_t`, `B_t`를 구한 뒤, 이 값들의 시간 변화 추세를 이용해 미래의 `A_t`, `B_t`를 예측한다.

정리하면, B.1은 관측자료를 이용해 도시별 시계열 모형과 국가 수준 power law 모형을 미리 학습하는 단계이다.

# 2. B.2 City-level Projection

B.2는 도시별 미래 인구 예측값 `P_hat_u,t+1`를 만드는 단계이다.

도시 인구는 두 종류의 예측값을 결합해서 만든다.

첫째, 도시별 시계열 모형에서 나온 예측값이다.

`P_hat_TS_u,t+1`

둘째, 국가 수준 power law 구조에서 나온 예측값이다.

`P_hat_PL_u,t+1`

TS 모형은 해당 도시의 과거 인구 변화 추세를 반영한다. 반면 PL 모형은 도시가 전체 도시체계 안에서 몇 위에 위치하는지, 그리고 전체 도시 규모분포가 어떻게 변화하는지를 반영한다.

예를 들어 도시 A에 대해 다음과 같은 예측값이 나왔다고 하자.

| 예측 종류 | 값 |
|---|---:|
| TS 예측값 `P_hat_TS` | 2,720 |
| PL 예측값 `P_hat_PL` | 2,800 |

이때 TS 가중치가 0.6, PL 가중치가 0.4라면 도시 A의 최종 도시-level 예측값은 다음과 같다.

`P_hat_A,t+1 = 0.6 * 2720 + 0.4 * 2800 = 2752`

즉, 도시 A의 예측 인구는 2,752명이 된다.

일반화하면 다음과 같다.

`P_hat_u,t+1 = (W_TS_u * P_hat_TS_u,t+1 + W_PL_u * P_hat_PL_u,t+1) / (W_TS_u + W_PL_u)`

이 과정을 모든 도시에 대해 수행하면 도시별 예측 인구가 만들어진다. 그런데 이 도시별 예측 인구를 모두 더했을 때, 외생적으로 주어진 총 도시인구와 일치하지 않을 수 있다.

예를 들어 예측된 도시 인구 합이 5,202명인데, 외생적으로 주어진 총 도시인구가 5,000명이라면 전체 도시 인구를 같은 비율로 줄여야 한다.

`lambda = 5000 / 5202 = 0.961`

따라서 각 도시의 예측 인구에 0.961을 곱해 총합을 5,000명으로 맞춘다.

| 도시 | 조정 전 `P_hat` | 조정 후 `P_hat` |
|---|---:|---:|
| A | 2,752 | 2,645 |
| B | 2,450 | 2,355 |
| 합계 | 5,202 | 5,000 |

이렇게 하면 도시별 상대적 크기는 유지하되, 전체 도시 인구는 외생적 총 도시인구와 일치하게 된다.

또한 미래 예측 과정에서 새롭게 생긴 도시는 과거 시계열이 없기 때문에 TS 모형을 사용할 수 없다. 이 경우에는 TS 가중치를 0으로 두고 PL 모형만 사용한다.

정리하면, B.2는 도시별 인구를 TS 모형과 PL 모형의 가중평균으로 예측한 뒤, 전체 도시인구 총량에 맞게 조정하는 단계이다.

# 3. B.3 Grid-level Projection

B.3은 격자별 미래 인구 `p_hat_i,t+1`를 예측하고, 이 격자 인구분포가 도시군 구조 및 국가 총인구와 일관되도록 조정하는 단계이다.

먼저 각 격자에 대해 여러 모형으로 raw prediction을 만든다. 여기에는 두 종류의 정보가 들어간다.

1. 해당 격자 자체의 과거 인구 변화  
2. 주변 9개 격자, 즉 9NN의 인구 변화  

사용되는 모형은 다음과 같다.

| 구분 | 모형 |
|---|---|
| 격자 자체 시계열 | ARI1, ARI2, CS, LL |
| 주변 9NN 시계열 | ARI1N, ARI2N, CSN, LLN |

각 모형에서 나온 예측값을 가중평균하면 격자별 1차 예측값이 만들어진다.

`p_hat_i,t+1`

이 값은 아직 도시 인구 `P_hat_u,t+1`와 맞춰진 값이 아니다.  
즉, 격자모형만으로 만든 raw prediction이라고 볼 수 있다.

# 4. 예시를 통한 전체 순서

이해를 돕기 위해 단순한 예시를 들어보자.  
격자가 일렬로 8개 있다고 가정한다.

    g1 — g2 — g3 — g4 — g5 — g6 — g7 — g8

도시 기준은 단순하게 다음과 같이 둔다.

> 인구 1,000명 이상인 격자들이 서로 붙어 있고, 그 묶음의 총인구가 2,000명 이상이면 도시군

2025년 격자모형의 raw prediction이 다음과 같이 나왔다고 하자.

| 격자 | raw `p_hat_2025` |
|---|---:|
| g1 | 1,300 |
| g2 | 1,200 |
| g3 | 950 |
| g4 | 920 |
| g5 | 1,150 |
| g6 | 1,050 |
| g7 | 980 |
| g8 | 700 |

1,000명 이상인 격자는 g1, g2, g5, g6이다.  
따라서 예측 격자 인구를 바탕으로 도시군을 재식별하면 다음과 같다.

| 1차 도시군 | 포함 격자 | raw 합계 |
|---|---|---:|
| A¹ | g1, g2 | 2,500 |
| B¹ | g5, g6 | 2,200 |

이제 앞서 B.2에서 만든 도시-level 목표 인구와 맞춰야 한다.  
예를 들어 도시 A의 목표 인구가 2,645명, 도시 B의 목표 인구가 2,355명이라고 하자.

---

## 4.1 도시 내부 격자 조정

도시 A¹은 g1, g2로 구성되어 있다.

`g1 + g2 = 1300 + 1200 = 2500`

그런데 도시 A의 목표 인구는 2,645명이다.  
따라서 조정계수는 다음과 같다.

`lambda_A = 2645 / 2500 = 1.058`

도시 A 내부 격자에 이 값을 곱한다.

| 격자 | raw | 조정 후 |
|---|---:|---:|
| g1 | 1,300 | 1,375 |
| g2 | 1,200 | 1,270 |
| 합계 | 2,500 | 2,645 |

도시 B¹도 같은 방식으로 조정한다.

`g5 + g6 = 1150 + 1050 = 2200`

도시 B의 목표 인구는 2,355명이므로,

`lambda_B = 2355 / 2200 = 1.070`

| 격자 | raw | 조정 후 |
|---|---:|---:|
| g5 | 1,150 | 1,230 |
| g6 | 1,050 | 1,125 |
| 합계 | 2,200 | 2,355 |

즉, 도시 내부 격자는 해당 도시의 예측 인구 `P_hat`에 맞춰 비례 조정된다.

일반화하면 다음과 같다.

`lambda_u = P_hat_u,t+1 / sum(p_hat_i,t+1 for i in city u)`

`p_hat_new_i,t+1 = lambda_u * p_hat_i,t+1`

---

## 4.2 도시 외부 격자 조정

도시 밖 격자는 g3, g4, g7, g8이다.

도시 밖 격자들은 특정 도시의 `P_hat`에 맞춰지는 것이 아니라, 국가 총인구에서 도시 인구를 뺀 나머지 인구에 맞춰진다.

예를 들어 2025년 국가 총인구가 8,600명이고, 총 도시인구가 5,000명이라면 도시 밖 격자가 가져야 할 인구는 다음과 같다.

`outside_target = national_total - total_urban_population`

`outside_target = 8600 - 5000 = 3600`

도시 밖 격자의 raw 합계는 다음과 같다.

`outside_raw_sum = 950 + 920 + 980 + 700 = 3550`

따라서 도시 밖 조정계수는 다음과 같다.

`lambda_outside = 3600 / 3550 = 1.014`

이 값을 도시 밖 격자에 곱한다.

| 격자 | raw | 조정 후 |
|---|---:|---:|
| g3 | 950 | 963 |
| g4 | 920 | 933 |
| g7 | 980 | 994 |
| g8 | 700 | 710 |
| 합계 | 3,550 | 3,600 |

이제 전체 격자 인구는 국가 총인구와 일치한다.

| 구분 | 조정 후 인구 |
|---|---:|
| 도시 A 내부 | 2,645 |
| 도시 B 내부 | 2,355 |
| 도시 외부 | 3,600 |
| 전체 | 8,600 |

일반화하면 다음과 같다.

`outside_target = national_total_t+1 - sum(P_hat_u,t+1 for all cities u)`

`lambda_outside = outside_target / sum(p_hat_j,t+1 for all outside grids j)`

`p_hat_new_j,t+1 = lambda_outside * p_hat_j,t+1`

# 5. Smoothing

rescaling 이후에는 도시 경계에서 값이 급격하게 변할 수 있다.

예를 들어 도시 B 내부의 g6은 1,125명인데, 바로 옆 도시 외부 격자인 g7은 994명일 수 있다.

    g5 — g6 — g7 — g8

이러한 경계의 불연속을 완화하기 위해 smoothing을 수행한다.  
smoothing은 각 격자의 예측값과 주변 9NN 평균값을 가중평균하는 방식으로 이루어진다.

예를 들어 smoothing 이후 값이 다음과 같이 바뀌었다고 하자.

| 격자 | rescaling 후 | smoothing 후 |
|---|---:|---:|
| g1 | 1,375 | 1,360 |
| g2 | 1,270 | 1,260 |
| g3 | 963 | 970 |
| g4 | 933 | 940 |
| g5 | 1,230 | 1,220 |
| g6 | 1,125 | 1,110 |
| g7 | 994 | 1,005 |
| g8 | 710 | 735 |

이 경우 g7은 smoothing 이후 1,000명 이상이 되었다.  
따라서 다시 도시군을 식별하면 g7이 도시 B와 연결될 수 있다.

---

# 6. 도시군 재식별과 반복

smoothing 이후 다시 도시군을 식별해보면, 1,000명 이상인 격자는 g1, g2, g5, g6, g7이다.

따라서 도시군은 다음과 같이 바뀐다.

| 2차 도시군 | 포함 격자 |
|---|---|
| A² | g1, g2 |
| B² | g5, g6, g7 |

처음에는 도시 B가 g5, g6으로 구성되어 있었지만, smoothing 이후 g7이 기준을 넘으면서 도시 B에 포함되었다.

즉,

`U^(1) != U^(2)`

이므로 아직 수렴하지 않았다.

이 경우에는 새로 식별된 도시군 `U^(2)`를 기준으로 다시 계산한다.  
즉, 도시 B를 이제 g5, g6, g7로 구성된 도시로 보고, 도시 순위와 도시 인구 `P_hat`을 다시 계산한다. 그리고 그 새 도시 `P_hat`에 맞춰 g5, g6, g7의 격자 인구를 다시 조정한다.

이 과정을 반복하다가, 조정 후 다시 도시군을 식별했을 때 이전 반복의 도시군과 같아지면 수렴한 것으로 본다.

`U^(k+1) = U^(k)`

수렴했다는 것은 다음을 의미한다.

> 최종 격자 인구분포로 다시 도시군을 그려도, 방금 조정에 사용한 도시군과 같은 도시군이 나온다는 뜻이다.

즉, 격자 인구분포와 도시군 경계가 서로 모순되지 않는 상태가 된 것이다.

# 7. 전체 순서 요약

Appendix B의 전체 계산 흐름은 다음과 같이 정리할 수 있다.

    1. 관측자료로 도시군을 식별하고 도시별 시계열을 만든다.
    2. 도시별 TS 모형과 국가 수준 PL 모형을 학습한다.
    3. 도시 TS 예측값과 PL 예측값을 결합해 도시별 P_hat을 만든다.
    4. 도시별 P_hat의 합이 총 도시인구와 맞도록 rescaling한다.
    5. 격자 TS 모형과 9NN 모형을 결합해 격자별 raw p_hat을 만든다.
    6. raw p_hat으로 미래 시점의 도시군을 재식별한다.
    7. 새 도시군 기준으로 도시별 P_hat을 업데이트한다.
    8. 도시 내부 격자는 해당 도시의 P_hat에 맞춰 조정한다.
    9. 도시 외부 격자는 국가 총인구에서 도시 인구를 뺀 나머지에 맞춰 조정한다.
    10. 도시 경계의 급격한 불연속을 줄이기 위해 smoothing한다.
    11. 조정된 p_hat으로 다시 도시군을 식별한다.
    12. 도시군이 이전 반복과 같으면 해당 시점의 결과를 확정한다.
    13. 도시군이 달라졌다면 새 도시군 기준으로 7~11번을 반복한다.
